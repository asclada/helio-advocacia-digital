### Decisões tomadas e por quê

1. **Contorno dourado, não contorno neutro nem pílula preenchida** — o
   Badge existe para comunicar confiança ("isto é uma credencial"), não
   para se misturar ao layout como um elemento estrutural neutro. Contorno
   neutro (`border-border`) já é o vocabulário de bordas/divisores comuns;
   pílula sólida (`bg-secondary`) competiria com o mesmo token usado em
   cards elevados. Ver raciocínio completo em `docs/specs/fase2-badge.md`.
2. **Sem prop `variant`** — só há um caso de uso confirmado (selo de
   credibilidade, sempre a mesma cor). Mesmo princípio já usado no Button
   ao não adicionar `size` sem caso de uso real.
3. **Sem `cva`** — `cva` orquestra múltiplas variantes; com um único
   estilo fixo, é abstração sem necessidade atual.
4. **Sem foco/hover/interatividade** — o Badge não é clicável nem
   dispensável. Diferente do Button, os critérios de foco visível da spec
   geral da Fase 2 não se aplicam (não é um elemento interativo);
   contraste AA continua se aplicando, e foi verificado reaproveitando o
   cálculo já feito na spec do Button para a mesma combinação de tokens
   (`text-gold-light` sobre fundo com tingimento `gold/5`, ~13:1).
